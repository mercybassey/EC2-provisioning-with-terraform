## Interview Talking Points

> "I built a production-grade MySQL infrastructure on AWS demonstrating advanced cloud architecture concepts:
> 
> 1. **Zero-trust security:** Eliminated SSH keys and public IPs by implementing AWS Systems Manager Session Manager with VPC endpoints, keeping all traffic on AWS's private network.
> 
> 2. **Cost optimization:** Reduced NAT Gateway costs by 60-95% through conditional resource deployment - internet access is enabled only during maintenance windows via Terraform variables.
> 
> 3. **Defense in depth:** Multiple security layers including network isolation (private subnet), firewall rules (security groups), IAM-based access control, and application-level security (MySQL localhost binding).
> 
> 4. **Infrastructure as Code:** Entire stack defined in Terraform with parameterized configuration, enabling consistent deployment across environments.
> 
> This architecture demonstrates understanding of AWS networking, security best practices, cost optimization strategies, and modern DevOps principles."
